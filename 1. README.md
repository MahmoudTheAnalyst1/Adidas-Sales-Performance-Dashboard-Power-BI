# Adidas Sales Performance Dashboard – Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze Adidas sales performance and provide useful business insights.

## Project Objectives
- Analyze total sales and profit.
- Evaluate sales performance by product and region.
- Identify profitable and loss-making sales.
- Analyze sales trends and business performance.
- Provide strategic recommendations based on the analysis.

## Tools & Technologies
- Power BI
- DAX
- Power Query

## Project File
Download the `.pbix` file from this repository and open it using Power BI Desktop.
